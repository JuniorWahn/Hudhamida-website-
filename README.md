# HUD HAMIDA Website

This is a responsive static website built from the supplied HUD HAMIDA company profile.

## Files
- index.html — website
- styles.css — design
- script.js — mobile menu and WhatsApp enquiry form
- assets/ — brochure photos and brand mark

## Publish for free
1. Create a GitHub account.
2. Create a new repository named `hud-hamida-website`.
3. Upload all files in this folder.
4. Open Settings → Pages.
5. Choose Deploy from branch → main → /root.
6. GitHub will give you a public website address.

The WhatsApp enquiry button uses the number shown in the supplied brochure: +232 34 051618.
